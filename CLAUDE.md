## Project Overview

This is a static personal portfolio website for a Data Analyst. The entire site is contained in a single `index.html` file with embedded CSS styling.

## Development

No build tools or dependencies are required. To preview changes, open `index.html` directly in a web browser.

## Architecture

- **index.html**: Single-page portfolio with all HTML and CSS inline
  - Uses Bootstrap 5 (CDN) for layout and components
  - Uses FontAwesome 6 (CDN) for icons
  - Uses Google Fonts (Inter) for typography
  - Dark theme with CSS custom properties for consistent colors

## Key Sections in index.html

- Hero section with profile image and CTA buttons
- About Me section
- Tech Stack icons display
- Portfolio Projects cards (3 projects)
- Footer with social links
